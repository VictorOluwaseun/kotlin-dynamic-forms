# Roadmap

## Before the first public release

- Run device tests on an emulator and physical Android device.
- Review with TalkBack, large fonts, dark mode and a small screen.
- Capture actual app screenshots and a short save/relaunch/restore recording.
- Review the API and naming, then tag a release with a reproducible build.

## Next SDK capabilities

- Localized labels and validation messages supplied by the host.
- Date fields, multiline text, sections and repeating groups.
- Compound conditions with explicit, versioned semantics.
- An XML/View renderer sharing the same core contract.
- Public API compatibility checks and dependency verification metadata.

## Host integration examples

- Remote schema retrieval with caching and schema-revision reconciliation.
- Durable submission queue, idempotency keys, retry policy and observable sync state.
- Draft retention, export and optional encrypted storage.

These are planned items, not existing capabilities.
